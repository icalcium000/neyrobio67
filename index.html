Запуск на BotHost (bothost.ru)

1. Хостинг Mini-App

Сохраните этот файл как index.html и загрузите в раздел Mini-App / статического сайта на bothost.ru. Скопируйте выданный HTTPS-адрес.

2. Авто-отправка конспектов в Telegram

Когда участник завершает опрос, приложение автоматически отправляет готовый конспект боту через Telegram.WebApp.sendData(). Также на каждом конспекте есть кнопка «В ТГ».

bot.py (aiogram 3 для BotHost) 
import asyncio, json
from aiogram import Bot, Dispatcher, F, types
from aiogram.filters import CommandStart
from aiogram.types import ReplyKeyboardMarkup, KeyboardButton, WebAppInfo

TOKEN = "ВАШ_ТОКЕН_БОТА"
WEBAPP_URL = "https://ВАШ_ДОМЕН.bothost.ru"
ADMIN_ID = 123456789  # Ваш Telegram ID для получения конспектов

bot = Bot(token=TOKEN)
dp = Dispatcher()

@dp.message(CommandStart())
async def cmd_start(msg: types.Message):
    kb = ReplyKeyboardMarkup(
        keyboard=[[KeyboardButton(text="Открыть ленту", web_app=WebAppInfo(url=WEBAPP_URL))]],
        resize_keyboard=True
    )
    await msg.answer("Нажмите кнопку ниже, чтобы начать:", reply_markup=kb)

@dp.message(F.web_app_data)
async def on_webapp_data(msg: types.Message):
    data = json.loads(msg.web_app_data.data)
    summary = data.get("summaryText", "Нет данных")
    await msg.answer("Спасибо! Ответы записаны.")
    await bot.send_message(ADMIN_ID, summary)

async def main():
    await dp.start_polling(bot)

if __name__ == "__main__":
    asyncio.run(main())
